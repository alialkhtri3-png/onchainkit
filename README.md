# OnchainKit 🚀

**Freedom-first Web3 toolkit for real-world crypto payments.**

OnchainKit is not just another Web3 library.  
It is a financial liberation toolkit built for developers and communities **locked out of traditional systems**.

No banks.  
No geo-restrictions.  
No permissions.

---

## 🌍 Why OnchainKit Exists

Millions of developers and users in regions like **Yemen, Africa, and parts of Asia** are excluded from global payments.

OnchainKit is built **for them first**.

---

## 🔥 What Makes OnchainKit Different?

- 🌐 Designed for restricted & unsupported countries  
- 💸 Real crypto payments (not Web2 middlemen)
- 🧱 No dependency on centralized payment providers  
- 🛡️ Users fully control their funds (100% self-custody)
- ⚡ Build dApps faster without Web3 complexity

---

## ⚙️ Core Features

- 🔐 Secure wallet connections
- ✍️ On-chain transaction signing
- 📜 Direct smart contract interactions
- 🧩 Ready-to-use UI components
- 🌐 EVM / Ethereum compatible chains
- 💳 Crypto payments for commerce & donations

# ChainCLI – Lightweight Base RPC Tool 🚀

![ChainCLI GIF](https://via.placeholder.com/600x200.png?text=ChainCLI+Demo)  
*مثال توضيحي لاستخدام الأداة على Termux*

---

## **نبذة عن المشروع**
**ChainCLI** هي أداة سطر أوامر **خفيفة الوزن** للاستعلام عن بيانات شبكة **Base** مباشرة عبر **JSON-RPC**، بدون الحاجة إلى مفاتيح API.  
- تعمل محليًا على **Termux** أو أي بيئة Linux صغيرة.  
- لا تعتمد على مكتبات أو Dependencies ثقيلة.  
- مناسبة للمطورين، الباحثين، وWeb3 builders.

---

## **الميزات الأساسية**
- جلب **Chain ID** للشبكة.
- جلب **آخر بلوك**.
- جلب **رصيد أي عنوان ETH**.
- سريع، خفيف، يعمل محليًا بدون إعدادات معقدة.
- جاهز للتوسعة: دعم Tokens، Gas، ENS، Multi-chain.

---

## **لماذا Base؟**
- رسوم منخفضة وفعالة.
- مدعومة من **Coinbase**.
- مثالية للأدوات الخفيفة والأتمتة.
